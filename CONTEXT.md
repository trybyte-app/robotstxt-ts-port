# Robots exclusion vocabulary

This glossary names the concepts used by the version 2 API, implementation, and documentation. Use these terms in code and prose so a "rule" means the same thing everywhere.

| Term                 | Definition                                                                                                                                                                                                                     | Avoid                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------- |
| Robots text          | The contents of a robots.txt file before the parser interprets it.                                                                                                                                                             | Robots body, source document                 |
| Directive            | A recognized or unrecognized name and value on one parsed line.                                                                                                                                                                | Command, instruction                         |
| User-agent group     | One or more adjacent `user-agent` directives followed by rules for those crawler identities.                                                                                                                                   | Agent block, section                         |
| Crawler identity     | The product token used to select user-agent groups. For `Product/Version`, the identity is `Product`.                                                                                                                          | User-agent string, bot name                  |
| Rule                 | An effective `allow` or `disallow` directive inside a user-agent group. An empty directive is not a rule.                                                                                                                      | Pattern, permission                          |
| Selected rules       | The rules merged from matching specific groups, or from global groups when no specific group matches. An empty specific group still suppresses global rules.                                                                   | Active rules, applicable policy              |
| Match decision       | The allowed or disallowed result for one crawler identity and URL.                                                                                                                                                             | Check result, verdict                        |
| Match evidence       | The source rule that decided a match, or the exact reason the matcher allowed a URL by default.                                                                                                                                | Match details, debug data                    |
| Parsed line          | The interpreted directive and diagnostic codes for one source line.                                                                                                                                                            | Parse event, callback result                 |
| Matching policy      | The named set of parsing and matching rules. Version 2 provides `google` and `rfc9309`; `google` is the default.                                                                                                               | Match strategy, behavior flags               |
| Google compatibility | The decisions and inspection data produced by Google's open-source parser and matcher after the package normalizes the crawler identity. This does not cover fetching, HTTP responses, redirects, caching, or download limits. | Google crawler emulation, Googlebot behavior |
